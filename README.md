# Cybersecurity Lab

A long-term practical cybersecurity laboratory documenting my development
from foundational security knowledge to incident response, DFIR,
detection engineering and security tooling.

## Objectives

- Build strong cybersecurity fundamentals
- Develop networking and operating system knowledge
- Learn Windows and Linux security
- Develop incident response and DFIR skills
- Learn detection engineering
- Study offensive techniques from a defensive perspective
- Build security tooling
- Investigate realistic security incidents
- Document methodology, evidence and conclusions

## Areas

- Security fundamentals
- Networking
- Linux
- Windows
- Web security
- Incident response
- Digital forensics
- Detection engineering
- Threat intelligence
- MITRE ATT&CK
- Security research

## Methodology

For each topic I try to answer:

1. What is it?
2. How does it work?
3. Why does security care?
4. How can it be abused?
5. How can it be detected?
6. How would I investigate it?
